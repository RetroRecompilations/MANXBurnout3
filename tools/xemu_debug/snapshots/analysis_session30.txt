== Key Discoveries ==

1. sub_000636D0 is INPUT NORMALIZATION, not physics
   - Reads raw integer input accumulators:
     0x4D652C = throttle (integer, e.g. 640)
     0x4D6530 = steering (integer, e.g. 480)
   - Uses timing delta: 0x4AE1FC = 0.0167 (1/60s)
   - Multiplies by screen constants: 0x557870=640.0, 0x5592C8=480.0
   - WRITES normalized float results to vel_ptr+8 and vel_ptr+C
   - vel_ptr = car_object+0x1B4 = 0x466DF0
   - vel_ptr+8 = 1.0 (full throttle), vel_ptr+C = 0.933 (steering)

2. Car object at 0x557880 is a COLOR/MATERIAL PALETTE
   - Contains values in 0.0-1.0 range (RGB-like)
   - Does NOT change during gameplay
   - NOT the runtime car physics object

3. Real physics body is NOT at 0x5FFF00
   - 0x5FFF00 is all zeros in xemu (our recomp fabricated this)
   - The real physics is deep in the game's object hierarchy

4. Game Manager Object
   - Pointer at 0x4AED9C = 0x3F9040
   - +0x00: vtable at 0x3AAD78 (state machine function table)
   - +0x40: 0x1E59000 (large heap alloc, possibly game world)
   - +0x48: 0x3C0800 (sub-object)
   - +0x6C: 0x83EEE200 (Xbox contiguous RAM, GPU/D3D)

5. Load Queue (0x4AEDDC)
   Files loaded during session:
   - Data/Global.txd
   - Data/GlobalUs.bin
   - Data/HeadUs.bin
   - pveh/vlist.bin
   - Tracks/tlist.bin

   - pveh/COMP/CAR3.bgv
   - pveh/COMP/CAR2.bgv
   - tracks/US/C3_V1/enviro.dat

6. sub_000110E0 (frame pump)
   - Only direct memory ref: 0x4AED9C (game manager ptr)
   - Everything else accessed via pointer dereferences
   - Operates through the game manager hierarchy

7. Game State Area (0x4D53B0-0x4D53C0)
   - 0x4D53B4 = 5 (could be a state value)
   - 0x4D53B8 = 5
   - 0x4D53BC = 1
   - 0x4D53BE = 0 (our "game state" byte)
   - 0x4D53C0 = float (22.35...) NOT an integer state

8. Xbox Kernel addresses

== Implications for Recomp ==

1. Our fake physics body at 0x5FFF00 is completely wrong - the real game
   stores input in vel_ptr+8/+C and physics state elsewhere in the object graph

2. sub_000636D0 output (vel_ptr+8, +C) feeds into the real physics engine
   which integrates position/velocity/heading

3. The game manager at 0x3F9040 is the key entry point to find all game state

4. Car world matrix is at 0x4D6850 - could write our position here for rendering

5. Camera viewport/frustum is at 0x4D9180 area - matches RenderWare camera struct

6. Physics parts array at 0x549000 area has per-body-part transforms

7. The 0x4DB000-0x4E0000 region is the hot physics simulation area
